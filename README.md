# FMP Analytics — Central de Dashboards

Plataforma interna da FMP que reúne os painéis analíticos migrados do Power BI.

- **[SPECS.md](SPECS.md)** — contrato de construção da aplicação. Leia antes de
  escrever qualquer código: arquitetura, padrão de dashboard, cache, design
  system, privacidade e checklist de entrega.
- **[README-deploy.md](README-deploy.md)** — Docker/EasyPanel, variáveis de
  ambiente, autenticação e cache dos dados.
- **[docs/](docs/)** — regras herdadas do Power BI e divergências documentadas.

```bash
npm install && npm run dev
```
